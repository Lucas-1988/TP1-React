# 🎧 Entrega TP4 - React

## 🚀 PROYECTO SPOTIFY CON REACT + VITE + TYPESCRIPT - ENTREGA 3

Este proyecto corresponde al TP4 del curso de React, donde incorporamos la obtencion de datos desde *servicios* para mejorar el rendimiento de una aplicación musical inspirada en Spotify.

---

## 🧩 Funcionalidades principales

- ✅ Página principal con listado de canciones (/)
- ✅ Página por categoría (/category/:id)
- ✅ Navegación entre rutas utilizando react-router-dom
- ✅ Componente Navbar para navegación global
- ✅ Obtener lista de canciones desde servicio
- ✅ Obtener detalles del artistas (/Artista/:id) desde servicios
- ✅ Mostrar estado de carga/error mientras se obtienen datos
- ✅ Crear canciones nuevas

---

## 🧠 Tecnologías utilizadas

- React + Vite
- TypeScript
- React Router DOM
- CSS Modules
- @fontsource/inter (para tipografía personalizada)
  

---

## 🛠 Cómo correr el proyecto

1. Clonar el repositorio:
   bash
   git clone [https://github.com/usuario/Lucas-1988/TP1-React.git]
   

2. Instalar dependencias:
   bash
   npm install
   

3. Correr la app:
   bash
   npm run dev
